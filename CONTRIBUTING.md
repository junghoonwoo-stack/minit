# Contributing to Minit

Minit is early. The most useful contribution is a real-world test.

## Try it

Run a local web app and publish it with:

```bash
minit run
```

When reporting a problem, please include:

- OS and CPU architecture
- Python version
- local app/framework and port
- the command you ran
- what you expected
- what happened instead

Please do not include API keys, secrets, private URLs, or sensitive application data.

Small fixes and focused pull requests are welcome.
